# Bokkisa Srinivas Vivek — Academic Website

A lightweight academic website designed for GitHub Pages.

## Files

- `index.html` — all website content
- `styles.css` — layout and visual design
- `script.js` — mobile navigation and footer year
- `assets/Vivek_CV.pdf` — downloadable academic CV

## Publish as your personal GitHub Pages site

### Recommended repository

Because your GitHub username is `srinivas12viv`, create a repository named:

`Srinivas12viv.github.io`

GitHub treats the repository name case-insensitively, but using lower-case is cleaner:

`srinivas12viv.github.io`

### Upload

Upload the contents of this folder to the **root** of that repository:

```text
srinivas12viv.github.io/
├── index.html
├── styles.css
├── script.js
└── assets/
    └── Vivek_CV.pdf
```

### Enable Pages

In the GitHub repository:

1. Open **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch.
5. Select `/ (root)`.
6. Save.

Your personal site should then be served from:

`https://srinivas12viv.github.io/`

Your existing project page can continue to live at:

`https://srinivas12viv.github.io/NorSand/`

## Update the website

Edit `index.html` whenever you:

- publish a new paper;
- start a new research project;
- receive an award;
- release software;
- give an invited talk;
- change institution or academic title.

Commit and push the change to `main`; GitHub Pages republishes the site.

## Replace the CV

Replace:

`assets/Vivek_CV.pdf`

with your latest CV while keeping the same filename. All CV links on the website will continue to work.

## Optional: Add a professional photograph later

A faculty/research website does not require a portrait. If you want one later:

1. Add `assets/profile.jpg`.
2. Insert the image into the hero section in `index.html`.
3. Use a professional, neutral-background photograph.

## Optional: Custom domain

If you later purchase a domain such as `srinivasvivek.com`, GitHub Pages supports custom domains. Configure the domain in **Settings → Pages → Custom domain**, then configure the DNS records with your domain registrar.

## Design philosophy

This site is deliberately:

- research-first;
- readable by a faculty search committee in under a minute;
- mobile responsive;
- free of frameworks and build dependencies;
- easy to maintain directly in GitHub.
